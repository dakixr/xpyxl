# xpyxl guide for LLMs

xpyxl builds styled Excel, HTML, PDF, and PNG reports by composing immutable
nodes. Users describe layout; xpyxl assigns coordinates.

```bash
pip install xpyxl
# or: uv add xpyxl
```

## Mental model and syntax

1. Builders use `[...]` to receive content: `x.row()["A", 1]`.
2. A sheet contains components; a workbook contains sheets.
3. Styles are composable values passed as `style=[...]`.
4. Rendering happens only when `save()`, `export()`, or `to_openpyxl()` is called.

```python
import xpyxl as x

report = x.workbook()[
    x.sheet("Summary", show_gridlines=False)[
        x.row(style=[x.text_2xl, x.bold, x.text_blue])["Q3 Sales"],
        x.table(
            header_style=[x.bold, x.text_white, x.bg_primary],
            style=[x.table_bordered, x.table_banded, x.table_compact],
        )[
            {"Region": "EMEA", "Units": 1200, "Price": 19.0},
            {"Region": "APAC", "Units": 900, "Price": 21.0},
        ],
    ]
]
report.save("report.xlsx")
```

Do not pass a builder itself into a layout. Index it first: use
`x.row()["value"]`, not `x.row()`.

## Components

All components accept composed styles where shown.

```python
# One cell; colspan/rowspan create an Excel merge anchored at this cell.
x.cell(style=[x.bold], colspan=3)["Quarterly summary"]
x.cell(rowspan=2)["Region"]

# Horizontal and vertical sequences of cells.
x.row(style=[x.bg_info])["A", 1, True]
x.col(style=[x.italic])["North", "South", "West"]

# Blank rows (or columns inside hstack), optionally with an explicit height.
x.space()
x.space(2, height=8.0)

# Layout containers. gap is blank rows for vstack and blank columns for hstack.
x.vstack(
    x.row()["First"],
    x.row()["Second"],
    gap=1,
    style=[x.border_all],
)
x.hstack(
    x.col()["Left", "A"],
    x.col()["Right", "B"],
    gap=2,
)
```

Scalar values in a row/column are ordinary 1x1 cells. Wrap a scalar in
`x.cell(...)` only when it needs its own style or merge. Nested stacks and
merged cells are supported:

```python
hero = x.vstack(
    x.row()[
        x.cell(style=[x.text_xl, x.bold, x.text_center], colspan=3)[
            "Q3 overview"
        ]
    ],
    x.row()[x.cell(rowspan=2)["EMEA"], "Q1", "Q2"],
    x.row()[1200, 1300],
)
```

### Tables and accepted data shapes

Mapping-based tables derive a header. `column_order=` controls its order;
missing record values become blank cells and later-discovered keys are appended.
A single record must be wrapped in a list (`x.table()[[{...}]]`); otherwise its
mapping is interpreted as the dict-of-columns form.

```python
# Sequence of records.
x.table(
    column_order=["Name", "Age"],
    header_style=[x.bold],
)[
    {"Age": 30, "Name": "Alice"},
    {"Age": 25, "Name": "Bob"},
]

# Dict of equal-length columns.
x.table()[
    {
        "Region": ["EMEA", "APAC"],
        "Units": [1200, 900],
    }
]

# Sequence of sequences or row nodes. This form has no derived header.
x.table(style=[x.table_bordered])[
    ["Name", "Age"],
    ["Alice", 30],
    x.row(style=[x.bold])["Total", 30],
]
```

### Reusable custom components

A custom component is normally a function returning `x.Node`. This keeps the
public API declarative and makes report pieces easy to test and reuse.

```python
def kpi(label: str, value: object) -> x.Node:
    return x.vstack(
        x.cell(style=[x.text_sm, x.text_gray])[label],
        x.cell(style=[x.text_2xl, x.bold, x.number_comma])[value],
        gap=1,
        style=[x.border_all, x.bg_info],
    )

dashboard = x.sheet("KPIs")[
    x.hstack(kpi("Revenue", 125_000), kpi("Orders", 4_210), gap=2)
]
```

## Sheets and workbooks

```python
summary = x.sheet(
    "Summary",
    background_color="#F8FAFC",
    show_gridlines=False,
)[x.row()["Ready"]]

details = x.sheet("Details")[x.row()["Item", "Value"]]
report = x.workbook()[summary, details]
```

Sheet names must be non-empty, unique ignoring case, at most 31 characters,
and cannot contain `[]:*?/` or a backslash. A workbook may mix generated and
imported sheets.

## Cell values and formulas

Supported values include `str`, `int`, `float`, `bool`, `None`, `Decimal`,
`date`, `datetime`, `time`, and `timedelta`. A string beginning with `=` is an
Excel formula. Other objects render as `str(value)` consistently across engines.

```python
from datetime import date
from decimal import Decimal

x.row()[
    date(2026, 8, 14),
    Decimal("19.95"),
    "=SUM(B2:B10)",
    None,
]
```

## Styling

Style order is compositional: later values override earlier values for the same
property. Styles on containers apply to their contents.

```python
money = x.Style(
    font_name="Arial",
    font_size=12,
    font_size_delta=1,
    bold=True,
    italic=False,
    mono=False,
    text_color="#0F172A",
    fill_color="#E2E8F0",
    horizontal_align="right",
    vertical_align="center",
    indent=1,
    wrap_text=True,
    shrink_to_fit=False,
    auto_width=True,
    row_height=22,
    row_width=14,
    number_format="$#,##0.00",
    border="medium",
    border_color="#2563EB",
    border_top=True,
    border_bottom=True,
    border_left=True,
    border_right=True,
    table_banded=False,
    table_bordered=False,
    table_compact=False,
)
x.cell(style=[money])[1250.5]

# Merge utilities directly when constructing reusable styles.
label = x.combine_styles([x.text_sm, x.bold], base=x.Style(text_color="#334155"))
```

Color helpers accept `RGB`, `#RGB`, or `#RRGGBB`:

```python
x.normalize_hex("#abc")  # "#AABBCC"
x.to_argb("#abc")       # "FFAABBCC"
```

Predefined style utilities:

- Typography: `text_xs`, `text_sm`, `text_base`, `text_lg`, `text_xl`,
  `text_2xl`, `text_3xl`, `bold`, `italic`, `mono`.
- Text colors: `muted`/`text_muted`, `text_primary`, `text_white`, `text_red`,
  `text_green`, `text_blue`, `text_orange`, `text_purple`, `text_black`,
  `text_gray`.
- Fills: `bg_red`, `bg_primary`, `bg_muted`, `bg_success`, `bg_warning`,
  `bg_info`.
- Alignment: `text_left`, `text_center`, `text_right`, `align_top`,
  `align_middle`, `align_bottom`.
- Text sizing: `wrap`, `nowrap`, `wrap_shrink`, `allow_overflow`,
  `row_height(22)`, `row_width(14)`.
- Border sides: `border_all`, `border_top`, `border_bottom`, `border_left`,
  `border_right`, `border_x`, `border_y`.
- Border widths/patterns: `border_thin`, `border_medium`, `border_thick`,
  `border_dashed`, `border_dotted`, `border_double`, `border_none`.
- Border colors: `border_primary`, `border_muted`, `border_red`,
  `border_green`, `border_blue`, `border_orange`, `border_purple`,
  `border_black`, `border_gray`, `border_white`.
- Tables: `table_bordered`, `table_banded`, `table_compact`.
- Formats: `number_comma`, `number_precision`, `percent`, `currency_usd`,
  `currency_eur`, `date_short`, `datetime_short`, `time_short`.

For custom borders, `Style.border` accepts `thin`, `medium`, `thick`, `dashed`,
`dotted`, `double`, `hair`, `dashDot`, `dashDotDot`, `mediumDashed`,
`mediumDashDot`, `mediumDashDotDot`, `slantDashDot`, or `none`.

## Saving and rendering engines

`save()` accepts a path, a binary stream, or no target (returns bytes).

```python
import io
from pathlib import Path

report.save("report.xlsx")                         # hybrid, the default
report.save("report.xlsx", engine="openpyxl")
report.save("report.xlsx", engine="xlsxwriter")
report.save("report.html", engine="html")

buffer = io.BytesIO()
report.save(buffer, engine="hybrid")

raw = report.save(engine="xlsxwriter")
assert isinstance(raw, bytes)
Path("report.xlsx").write_bytes(raw)
```

- `hybrid`: fast generated sheets plus high-fidelity imported sheets; best
  default for `.xlsx`.
- `openpyxl`: generated and imported sheets; choose it for direct OpenPyXL
  workflows.
- `xlsxwriter`: fast, memory-efficient generation; does not support
  `import_sheet()`.
- `html`: self-contained browser-viewable HTML bytes; also renders imported
  sheets, with HTML-appropriate formatting.

## Importing existing sheets

`import_sheet()` accepts a path, workbook bytes, or a binary stream. It copies a
source sheet without translating it and can rename it or override gridlines.

```python
cover = x.import_sheet(
    "template.xlsx",
    "Cover",
    name="Cover Page",
    show_gridlines=False,
)

report = x.workbook()[
    cover,
    x.sheet("Data")[x.table()[[{"Item": "A", "Value": 1}]]],
]
report.save("combined.xlsx")  # hybrid or openpyxl; not xlsxwriter
```

Imports preserve cells, formulas, styles, merges, row/column dimensions,
freeze panes, filters, named styles, images, charts, and relevant sheet
properties supported by the source workbook.

## Advanced OpenPyXL access

Use `to_openpyxl()` when xpyxl should build the report but OpenPyXL should make
the final advanced edits.

```python
native = report.to_openpyxl()
native["Data"].freeze_panes = "A2"
native.save("advanced.xlsx")
```

## PDF and PNG export

Chromium is the default visual renderer and must be installed locally. It is
auto-discovered, or selected with `XPYXL_CHROMIUM_PATH`/`chromium_path=`.

```python
report.export("report.pdf")
report.export("summary.png", sheet="Summary", scale=2)

pdf_bytes = report.export()
png_bytes = report.export(format="png", sheet=0)
```

PDF includes all sheets unless `sheet=` selects one. PNG is one sheet and
requires `sheet=` for multi-sheet workbooks. `sheet` accepts a name or zero-based
index. `scale` controls PNG density.

For fully in-process export, install the optional renderer:

```bash
pip install "xpyxl[reportlab]"
```

```python
report.export("report.pdf", renderer="reportlab")
report.export("summary.png", renderer="reportlab", sheet="Summary", scale=2)
```

## Large reports and streaming

xpyxl streams large generated workloads through the hybrid and xlsxwriter
engines when layout permits. For best peak memory, provide a custom re-iterable
`Sequence` that creates rows/components on demand. Do not use a one-shot
generator: validation and rendering need repeatable passes.

```python
from collections.abc import Iterator, Sequence
from typing import overload

class GeneratedRows(Sequence[dict[str, object]]):
    def __init__(self, count: int) -> None:
        self.count = count

    def __len__(self) -> int:
        return self.count

    @overload
    def __getitem__(self, index: int) -> dict[str, object]: ...

    @overload
    def __getitem__(self, index: slice) -> Sequence[dict[str, object]]: ...

    def __getitem__(
        self, index: int | slice
    ) -> dict[str, object] | Sequence[dict[str, object]]:
        if isinstance(index, slice):
            return tuple(self[i] for i in range(*index.indices(self.count)))
        if index < 0:
            index += self.count
        if not 0 <= index < self.count:
            raise IndexError(index)
        return {"id": index, "value": index * 2}

    def __iter__(self) -> Iterator[dict[str, object]]:
        for index in range(self.count):
            yield {"id": index, "value": index * 2}

large = x.workbook()[
    x.sheet("Data")[x.table()[GeneratedRows(1_000_000)]]
]
large.save("large.xlsx", engine="xlsxwriter")
```

The same pattern works for a `Sequence[x.Node]` passed to `sheet()[...]`, which
supports large collections of reusable custom components without materializing
them all at once.
